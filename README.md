A standalone GitHub-compatible git forge in a single Node process: git smart HTTP (protocol v2 fetch, receive-pack), REST v3, GraphQL v4, and an MCP endpoint — no git binary, no database, and no dependencies beyond the Node standard library.

## Run it

```sh
node --experimental-strip-types main.ts
```
